# 5-Recipe-Builder

A personal mobile app for managing pantry inventory, generating recipes, and creating shopping lists.

- AI-powered recipe generation
- Shopping list creation
- Step-by-step cooking guidance

## Tech Stack

- React with TypeScript
- OpenAI Agent SDK
- localStorage for persistence

## Setup

```bash
npm install
npm start
```
